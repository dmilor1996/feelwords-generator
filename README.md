# WordVault Studio

Статический редактор филвордов 15×15: книги, свободный черновик, библиотека, проверка сеток и экспорт.

## Разработка

Сборка для публикации не нужна. GitHub Pages обслуживает `index.html` и `assets/` из корня репозитория. Для тестов: Node.js 22+, `npm ci`, затем `npm test`.

- `assets/app.js` — генератор, редактор, книги, синхронизация и события интерфейса.
- `assets/studio-core.js` — история редактора и правила проверки качества, без зависимости от DOM.
- `assets/print-layout.js` — единая разметка A4 для предпросмотра и печати/PDF.
- `assets/base.css` — общие компоненты; `assets/studio.css` — визуальная система и адаптивная компоновка.

## Поведение

Свободный черновик и темы книг изолированы. История хранит до 30 версий на контекст и до 120 контекстов локально на устройстве, отдельно от облачной синхронизации. Ctrl/⌘ Z и Ctrl/⌘ Shift Z работают вне текстовых полей; внутри полей сохраняется стандартная отмена ввода.

«Создать недостающие сетки» сохраняет существующие варианты. «Пересоздать все» требует подтверждения и сохраняет прежние сетки в локальной истории. Пакетная генерация сохраняет каждую завершённую тему и поддерживает остановку. Экспорт не генерирует и не изменяет сетки.

Проверка качества ищет отсутствующие слова, повторные вхождения, смешанные алфавиты, ошибки координат, несоответствие направлений и пересечений выбранным настройкам. Печатный экспорт блокируется при ошибках; исходник JSON доступен всегда. PDF использует системное окно печати. Длинные списки слов продолжаются на отдельных страницах. SVG/PNG имеют самостоятельный типографский макет с собственным предпросмотром; несколько листов выгружаются ZIP-архивом.

XLSX, ZIP и облачная синхронизация используют прежние внешние библиотеки. Рабочие данные и существующая схема синхронизации сохранены; персональные данные не включаются в исходный код.

## Проверки

`tests/editor-isolation.test.cjs` проверяет прежние гарантии разделения редакторов и отмену запоздавшей генерации. `tests/studio.test.cjs` исполняет приложение с настоящей HTML-структурой в DOM-окружении, проверяет историю, пакетную генерацию, качество, экспорт, навигацию и пагинацию. Эти проверки не заменяют визуальную проверку в браузере.
